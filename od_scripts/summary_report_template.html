Sanity check

Diversity vs. volume

real_all_matched holds the exact same train-set size as real_basev2 (6,999 images) but splits that budget across two synthetic sources instead of one. If the size-matched arm tracks real_all (34% more images, same two sources) rather than real_basev2, the gain is diversity of sources, not raw frame count.

Diagnostic, not a selection metric

Train-set fit: real vs. each synthetic source

Never used to pick a winner — validation stays real-only, always. But the gap between how well a checkpoint fits its own synthetic training frames and how it does on real valid is the clearest read on domain gap per source.

Method. RF-DETR Base, COCO pretrain, identical hyperparameters across every arm (AdamW lr 1e⁵⁴ / encoder 1.5e⁵⁴, batch 4 × grad-accum 4). LR: ReduceLROnPlateau on EMA mAP@50:95 (factor 0.1, patience 3), early stop patience 8. Deployable checkpoint = best EMA. Validation is always the 858-image LOCO subset-3 — never trained on by any arm, never mixed with synthetic frames. Full protocol in od_scripts/README.md.
